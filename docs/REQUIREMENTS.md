# 第一阶段需求说明

## 1. 产品目标

知闲第一阶段验证一个核心假设：用户能否在英文阅读场景中自然沉淀生词，并通过间隔复习持续掌握这些词。产品同时提供传统词书学习入口，使系统既能主动学习，也能承接阅读中的偶遇词汇。

## 2. 目标用户

- 希望通过真实英文文章提升词汇和阅读能力的学习者
- 需要一套轻量、自托管英语学习工具的个人用户
- 桌面与移动浏览器用户

## 3. 核心闭环

1. 用户选择词书并设置每日新词目标。
2. 系统安排到期复习词和当日新词。
3. 用户根据掌握程度提交“忘记 / 困难 / 认识 / 简单”。
4. 用户阅读分级文章，点击生词查看释义并加入生词本。
5. 文章中的生词进入后续复习队列，学习结果汇总到仪表盘。

## 4. 第一阶段范围

### 用户与设置

- 邮箱密码注册、登录、退出
- 昵称、每日新词目标、英语水平设置
- JWT 身份认证及用户数据隔离

### 单词与词书

- 浏览内置词书及进度
- 选择当前词书
- 获取当日学习队列
- 查看词义、音标、例句和例句翻译
- 提交学习评分并计算下次复习时间

### 生词本

- 手工或从文章加入单词
- 查看来源、加入时间和熟练度
- 删除生词、搜索生词

### 文章阅读

- 浏览文章列表与难度、主题、预计时间
- 按句展示中英文内容
- 点击英文单词查看释义
- 展开/收起单句翻译
- 收藏/取消收藏句子
- 将已知词典中的单词加入生词本

### 数据看板

- 今日待复习、今日已学、累计掌握、生词数量
- 连续学习天数
- 最近学习活动与当前词书进度

## 5. 明确不在第一阶段

- 邮件验证、密码找回、第三方登录
- PDF 上传、OCR、图片识别
- 单词/句子云端语音与发音评分
- AI 自动生成文章和 AI 动态规划（仅保留接口边界）
- 社交、排行榜、付费、后台管理系统
- 多设备实时同步冲突处理

## 6. 验收标准

- 新用户能够注册并登录，且只能访问自己的学习数据。
- 用户选择词书后能获得学习队列，评分后复习日期发生合理变化。
- 用户能在文章中查看单词释义、单句翻译、收藏句子和加入生词本。
- 仪表盘的数据随学习和收藏操作更新。
- 360px 宽移动页面与常见桌面宽度均可完整操作。
- 本地无需 PostgreSQL 即可启动；Docker Compose 能切换到 PostgreSQL。
- 后端自动化测试、前端 lint/build、Compose 配置检查全部通过。
