# 项目当前状态

最后核对：2026-09-08。本次变更的上游基线是 `main` 提交 `c164543`，当时与 `origin/main` 一致。

## 1. 一句话状态

知闲当前是可本地运行、可通过 Docker Compose 部署的英语学习模块化单体。第一阶段学习闭环、第二阶段受限工具型 AI 学习助手，以及固定来源、可审计的英文词库导入流水线已经落地。合并去重的基础词库已进入 Git，并通过全新 SQLite 和 Docker/PostgreSQL 导入验证。

FastAPI 应用版本为 `0.2.0`。当前不是静态原型：前后端、数据库迁移、测试、CI、容器和备份脚本均已存在。

## 3. 已实现产品范围

### 第一阶段：学习闭环

- 邮箱密码注册、JWT 登录、个人资料、英语等级、每日新词量和时区。
- 公共词典与词书、当前词书选择、学习队列和学习进度。
- SM-2 风格的确定性复习算法与四档评分。
- 用户生词、多个生词本、来源、备注和熟练度。
- 公共文章、个人 AI 草稿、逐句中英阅读、查词和句子收藏。
- 今日数据、累计掌握、连续学习和最近活动仪表盘。
- 桌面和移动端应用壳、登录页及主要业务页面。

当前主要前端路由：

```text
/login              /register
/dashboard          /learn
/wordbooks          /vocabulary
/articles           /articles/[id]
/assistant          /profile
```

### 第二阶段：学习 Agent

- 用户级 DeepSeek、MiniMax 配置，服务端 Fernet 加密 API Key。
- SSE 流式对话、持久化会话/消息、Token 用量和工具审计。
- 学习历史、今日快照、未来计划预测、易错词和词典查询。
- 受限站内导航、多生词本操作、破坏性操作二次确认。
- 结构化例句、个人文章草稿和明确授权的长期学习偏好。
- 单 Agent、有界工具循环；当前没有子 Agent、向量库或跨会话自动检索。

实现细节见 `phase-2/AGENT_IMPLEMENTATION.md`。

## 4. 数据与测试现状

- 全部 ORM 实体集中在 `apps/api/app/models/entities.py`，共覆盖账号、学习、阅读、生词本、每日计划和 AI 会话域。
- `apps/api/app/db/seed.py` 仍只提供 24 个示例词、1 本示例词书和 3 篇文章；正式词库由独立导入器维护，不塞入 seed。
- `zhixian-core-en-v1` 合并 CET-4、CET-6、考研通用、考研英语一/英语二和 IELTS：源数据 21,739 条，最终 7,416 个唯一词条、19,372 条去重来源关联。规范化 JSONL、manifest、哈希、质量报告和许可说明进入 Git；运行时数据库文件仍不入库。
- 后端当前有 22 个测试函数，新增覆盖词库规范化、授权门禁、数据包哈希/往返、唯一性和重复导入幂等性。
- 前端当前依赖 ESLint、TypeScript 生产构建校验，尚无组件/端到端测试套件。
- CI 定义在 `.github/workflows/ci.yml`，对 `main` push 和 Pull Request 运行。

本次实测：Python 3.13 下后端 `22 passed`（另有 1 条 Starlette 依赖弃用警告）；前端 ESLint 和 Next.js 生产构建通过；Compose 配置通过。本机已安装 Docker/Compose/Buildx + Colima，从空 PostgreSQL 17 volume 启动 API 后得到 `0004 (head)`、健康接口正常、7,416 个词书成员、19,372 条来源关联和 1 本已发布词书；第二次导入所有变更计数均为 0。演练完成后已删除临时容器和验证数据卷。
