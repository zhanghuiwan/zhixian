# 项目当前状态

最后核对：2026-09-15。

## 1. 一句话状态

知闲当前是可本地运行、可通过 Docker Compose 部署的 AI 英语学习模块化单体。AI 对话是主页，词书、单词学习、连续阅读、句子收藏和学习日历已经形成一套完整工作台。固定来源、可审计的统一词典进入 Git，并在产品中按六个来源发布为独立系统预设词书。

FastAPI 应用版本为 `0.3.0`。当前不是静态原型：前后端、数据库迁移、测试、CI、容器和备份脚本均已存在。

## 3. 已实现产品范围

### 第一阶段：学习闭环

- 邮箱密码注册、JWT 登录、个人资料、每日新词量和时区。CEFR 用户等级已从产品界面和 Agent 上下文撤下，旧字段仅作兼容保留。
- 公共词典与词书、当前词书选择、学习队列和学习进度。
- SM-2 风格的确定性复习算法与四档评分。
- 用户生词、多个生词本、来源、备注和熟练度。
- AI 可在词典未收录时，经用户明确同意创建私有词条；系统词与“我的新增”词有统一来源标记和独立筛选入口。
- 公共文章、个人 AI 草稿、逐句中英阅读、查词和句子收藏。
- 今日数据、累计掌握、连续学习和最近活动仪表盘。
- 桌面和移动端应用壳、登录页及主要业务页面。
- AI 对话主页；一级导航收敛为 AI 对话、学习、记录，学习中心聚合单词、词书、阅读、句子和我的新增单词。
- 六本独立系统预设词书与个人词书统一入口，单词进度跨词书共享。
- 专注单词学习页、连续文章阅读、选区工具条、文章上下文 AI 和阅读位置恢复。
- 句子收藏搜索/筛选/笔记，以及按用户时区生成的月历和每日概况。

### 第二阶段：学习 Agent

- 用户级 DeepSeek、MiniMax 配置，服务端 Fernet 加密 API Key。
- SSE 流式对话、持久化会话/消息、Token 用量和工具审计。
- 学习历史、今日快照、未来计划预测、易错词和词典查询。
- 受限站内导航、多生词本操作、破坏性操作二次确认。
- 结构化例句、个人文章草稿和明确授权的长期学习偏好。
- 单 Agent、有界工具循环；可按关键词检索当前用户的全部持久化会话，当前没有子 Agent、向量库或语义检索。
- 主页历史会话在桌面与移动端均默认收起；只读查询工具状态在本轮回答结束后清理，不再堆积到会话底部。
- 未手动选择会话时按用户本地日期复用当天默认会话；“新对话”始终创建独立手动会话。
- 纯英文单词、句子和长文采用确定性输入分类：默认查词或翻译，不例行追加泛化建议。查词按固定 Markdown 结构覆盖中英释义、音标、分义项语境、词形语法、常见用法、例句和易混词；句子翻译固定输出可独立收藏的自然译文及语义、表达、语法和语境说明，长文优先完整分段翻译后再补充语篇分析。
- Assistant 正文使用不执行原始 HTML 的 Markdown/GFM 渲染；服务端随最终消息持久化上下文操作，前端按白名单执行加入词本、收藏句子、保存阅读和开始学习。
- 完整 AI 讲解只用于展示和会话历史：已有单词加入词本时只保存词条关联，自定义词只保存受 schema 限制的核心词典字段，句子收藏只提取“中文翻译”区的规范译文。

实现细节见 `phase-2/AGENT_IMPLEMENTATION.md`。

## 4. 数据与测试现状

- 全部 ORM 实体集中在 `apps/api/app/models/entities.py`，共覆盖账号、学习、阅读、生词本、每日计划和 AI 会话域。
- `apps/api/app/db/seed.py` 提供 24 个兜底示例词和 5 篇原创示例文章；每位用户首次初始化 4 条示例句子收藏，示例删除后不会在重启或登录时复活。
- `zhixian-core-en-v1` 将六个来源的 21,739 条记录合并为 7,416 个唯一词典条目、19,372 条去重来源关联；产品只发布四级、六级、考研通用、考研英语一、考研英语二和雅思六本系统预设词书。
- 后端当前有 35 个测试函数，覆盖词库导入、迁移、用户隔离、私有自定义词、跨会话检索、当日会话、上下文操作、个人词书、评分幂等、阅读进度、学习日历和示例收藏初始化。
- 前端当前依赖 ESLint、TypeScript 生产构建校验，尚无组件/端到端测试套件。
- CI 定义在 `.github/workflows/ci.yml`，对 `main` push 和 Pull Request 运行。

本次实测：Python 3.13 下后端 35 项测试通过（仅有 1 条 Starlette 依赖弃用警告）；前端 ESLint 和 Next.js 生产构建通过。SQLite 已覆盖 `0006 → 0007` 带旧会话升级；Docker PostgreSQL 17 已升级到 `0007` 并通过健康检查。MiniMax-M3 使用仓库外临时 Key 在一次性数据库中完成真实端到端冒烟，确认详细查词/翻译格式、Tool Call、规范操作 payload、SSE 和会话持久化，输出未包含 Key 或回答正文。既有词库基线为 7,416 个唯一词、6 本系统预设词书、5 篇文章。桌面端和 360px 页面仍需在本次交互改动合入前完成最终人工复核。
