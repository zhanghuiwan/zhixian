# 首页闲闲动作位图

2026-10-29。平台：Android / Expo React Native。来源：内置 Image Gen，使用已批准的整块连续绿冠母版与工程中的 neutral.png 作身份参考。用户本次授权动作、表情、时间与天气延展；这六张新图属于已实现静态延展，尚未获用户逐张确认，不替代角色母版。

## 图像与动画边界

这些是六张不同动作／表情的静态PNG和一张中性归一化副本。运行时的短位移、旋转与淡入由应用组件实现；没有制作骨骼、连续肢体帧、口型、Rive文件或Rive状态机。不将静态姿态数称作完成的Rive动画数量。

气泡文字由界面渲染，不在PNG内。PNG不承担学习结果或请求状态的唯一通知。减少动态效果时保留静态姿态和文字交互。

## 来源与检查

- 已批准母版：角色目录 source/reference/approved-unified-canopy-v2/approved-front-side-top.png；仅身份获批。
- 使用规范：角色目录 design.md、app-web-guidelines.md、motion-handoff.md。
- 原有 neutral.png 保持原样。idle.png只进行alpha边界裁切、等比缩小、透明居中与脚底对齐。
- 新图使用内置 image_gen 工具，未用API密钥或CLI；提示词完整记录在仓库 docs/design/home-companion-2026-10-29/asset-prompts.json。原始生成路径、源hash和导出hash保留于 manifest.json。
- 图像艺术修正通过 Image Gen；sharp仅做机械裁切、缩放、透明排版和评审板合成，未手绘或重构角色。
- 逐张看图检查：绿冠连为一块；无木色分叉、无叶脉；三瓣绿叶掌直接连身；恰好两脚、无尾巴；冠掌脚不裁切；无文字。
- 阅读图检查：书在嘴下、两脚可见、没有人类手指或木色腕块。雨天图检查：伞完整、不遮住脸，角色颜色与其余姿态一致。
- 思考图初稿曾出现抬掌第四瓣歧义，修订为侧放三瓣掌后采用；弃稿仅留工具生成目录，不在App打包。
- 浅深色机械合成样本：docs/design/home-companion-2026-10-29/action-contact-sheet.png。此图是资产评审样本，不是App实际截图或真机动画验收。

生成与静态图像检查通过不等于运行时验收通过；页面布局、点击切换、后台停止与减少动态效果由本次主页实现另行验证。
