# Generated mobile visuals

These transparent PNG assets were created with the built-in OpenAI image generation tool for the Android app's “quiet study garden” visual system.

- `study-garden-v1.png`: a paper-clay open book, flashcards, pen, and growing leaves for the learning dashboard.
- `xianxian-thought-seed-v1.png`: a frosted-glass leaf seed with layered paper and brass orbits for the assistant home.
- `profile-growth-v1.png`: a seven-leaf paper-clay learning tree for the profile dashboard.

The corresponding `*-mobile-v1.png` files are downscaled delivery variants used by the app. They reduce the three bundled images from roughly 4.5 MB to roughly 1.35 MB while preserving transparent backgrounds; the original generated files remain as source assets.

The shared prompt direction specified a deep teal, mist green, almond paper, and restrained ochre palette; tactile paper, clay, glass, and brass materials; transparent backgrounds; and no text, logos, mascots, robots, neon, or purple-blue AI gradients.
